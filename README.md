# 2進数(二進法) ⇔ 10進数・ひらがな・アルファベット 変換ツール

> WebベースのUIで、2進数(二進法)・10進数・ひらがな・アルファベット・テキストの相互変換を簡単に行えるツールです。全角数字自動変換、UIのひらがな表示、ライト/ダーク/端末モード切替に対応しています。

---

## 🔧 機能概要

- ✅ 2進数(二進法) → 10進数 変換（符号付き2の補数対応）  
- ✅ 10進数 → 2進数 変換（正負の整数、全角数字の自動正規化対応）  
- ✅ ひらがな・アルファベット・テキスト ⇔ 2進数 相互変換（UTF-8 / ASCII）  
- ✅ UIのひらがな（ふりがな）表示 / 標準表記の切替  
- ✅ ライトモード / ダークモード / 端末モード自動切替  
- ✅ スマホ対応レスポンシブUI

---

## Binary (Base 2) ⇔ Decimal / Text Converter Tool

> A web-based UI tool that allows easy conversion between binary, decimal, hiragana, alphabet, and UTF-8 text. Supports UI hiragana (furigana) reading mode, light/dark modes, and automatic full-width character normalization.

---

## 🔧 Features

- ✅ Binary to Decimal conversion (supports two's complement for signed values)  
- ✅ Decimal to Binary conversion (supports positive/negative integers & full-width number auto-conversion)  
- ✅ Text (Hiragana, Alphabet, Japanese) ⇔ Binary bidirectional conversion (UTF-8 / ASCII)  
- ✅ UI language display switch (Standard / Hiragana mode)  
- ✅ Light mode / Dark mode / System color mode auto-switching  
- ✅ Responsive design optimized for smartphones
